# Branch working context

These notes are **optional and local**: add Markdown files next to this README if you use separate worktrees or agents. They are **gitignored** (see `.gitignore`: `docs/branches/CONTEXT-*.md`).

Suggested filenames (create them locally when needed):

| Worktree / branch | File |
|-------------------|------|
| `main` | `CONTEXT-main.md` |
| `demo/quick-demo` | `CONTEXT-demo-quick-demo.md` |
| `product/platform` | `CONTEXT-product-platform.md` |

All three lines share the same codebase; differences are **intent and permitted scope**. Prefer **merging `main` into your line** periodically so docs and shared UI fixes stay aligned.
